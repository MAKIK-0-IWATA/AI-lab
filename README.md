# AI lab

AIを道具として使いながら作った、小さなWebアプリの置き場所です。

🔗 **https://makik-0-iwata.github.io/ai-lab/**

---

## 置いてあるもの

| アプリ | 内容 |
|---|---|
| [**SG用語ドリル**](./sg-terms/) | 情報セキュリティマネジメント試験（SG）の頻出 **311語**。カテゴリ別に絞り込み、略語は正式名称つき |
| 試験対策としてご利用の場合は、公式教材および [IPA](https://www.ipa.go.jp/shiken/) の公開情報で必ずご確認ください。

## つくりかた

- **1アプリ ＝ 1フォルダ、1ファイル完結**
- **外部ライブラリ・CDNは使いません**（HTML / CSS / JavaScript のみ）
- スマホ優先。ダークモード対応
- インストール不要。ブラウザだけで動きます
